# Checklist nộp bài

## Sản phẩm

- [ ] Một file PBIX
- [ ] Notebook hoặc script chính cho chuẩn bị dữ liệu và EDA
- [ ] Notebook hồi quy tuyến tính
- [ ] Dữ liệu đã làm sạch dùng cho dashboard
- [ ] README hoặc báo cáo ngắn
- [ ] Slide thuyết trình 7–10 trang
- [ ] Ảnh mô hình dữ liệu và ảnh dashboard
- [ ] Ghi chú KPI/DAX
- [ ] Ghi chú giả định và giới hạn
- [ ] Ghi chú quyền riêng tư và chia sẻ dữ liệu
- [ ] Bảng phân công và bằng chứng các milestone

## Kiểm tra kỹ thuật

- [ ] Có ít nhất 1 trang dashboard, tối đa khoảng 6–7 visual chính mỗi trang
- [ ] Có ít nhất 5 measure, trong đó ít nhất 2 measure vượt mức SUM/COUNT
- [ ] Measure chính đã kiểm tra trong ít nhất 2 ngữ cảnh filter/slicer
- [ ] Có thống kê mô tả, ít nhất 1 so sánh nhóm và 1 phân tích mối quan hệ
- [ ] Hồi quy có đánh giá trên tập kiểm tra và so sánh với mốc đơn giản
- [ ] Notebook chạy lại được từ đầu đến cuối trên máy khác
- [ ] Kết luận phân biệt rõ mối liên hệ và quan hệ nhân quả
- [ ] Có khai báo hỗ trợ AI trong README
- [ ] Mọi thành viên hiểu toàn bộ logic dự án và có phần đóng góp rõ ràng
